# Command Line Usage

```bash
# Basic usage
./encode-orc project.yaml

# Output to specific directory
./encode-orc project.yaml --output /path/to/output

# Verbose logging
./encode-orc project.yaml --verbose

# Help information
./encode-orc --help
```
