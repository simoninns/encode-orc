# Configuration Examples

See the `example-projects/` directory for complete working examples:
- `ntsc-cav.yaml` - NTSC test pattern
- `pal-cav.yaml` - PAL test pattern
- `ntsc-sound.yaml` - NTSC with audio simulation
- `ntsc-dropout.yaml` - NTSC with simulated dropout effects
