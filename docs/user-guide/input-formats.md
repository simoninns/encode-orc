# Input Formats

encode-orc supports multiple input file formats:

| Format | Extension | Notes |
|--------|-----------|-------|
| YUV422 | `.raw` | Raw uncompressed video data |
| PNG | `.png` | Single frame or sequence |
| QuickTime | `.mov` | Video file format |
| MP4 | `.mp4` | MPEG-4 video format |
