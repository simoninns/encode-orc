# Output Formats

## Composite Mode
Generates traditional composite video:
- `output.tbc` - Composite field video
- `output.tbc.db` - SQLite metadata database

## Y/C Mode (S-Video)
Separates luma and chroma:
- `output.tbcy` - Luma channel
- `output.tbcc` - Chroma channel
- `output.tbc.db` - SQLite metadata database

For details, see [Output Formats](../technical/output-formats.md).
