# Virtual Test Discs

This section documents the comprehensive virtual LaserDisc and tape-style fixture projects in `ggv-tests/` and their expected outputs in `ggv-output/`.

The virtual test disc documentation is split by video format:

- [PAL virtual test discs](virtual-test-discs-pal.md)
- [NTSC virtual test discs](virtual-test-discs-ntsc.md)
- [PAL-M virtual test discs](virtual-test-discs-palm.md)

Each format page includes the CAV composite, CLV composite, and VITC Y/C variants.
