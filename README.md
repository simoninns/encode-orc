# encode-orc

![](docs/encode-orc/assets/encode-orc_logotype.png)

Encode-Orc is a PAL, PAL-M and NTSC encoder capable of producing ld-decode and vhs-decode compatible TBC files (and SQLite metadata) to assist with testing including support for dual-TBC YC files.

Please see the [Encode-Orc Documentation](https://simoninns.github.io/encode-orc/) for details.
